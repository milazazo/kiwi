rules

  • You can be currently or previously based in New Zealand (if previously based here, please specify in the form). Your content doesn't need to be NZ-focused.
  • This isn't limited to personal websites; portfolio sites and non-commercial sites run by groups are also welcome as long as you follow the other rules.
  • No single page websites (Carrd, Strawpage, etc.), social media (Tumblr, Instagram, etc.), or commercial websites. It's OK if your site has a shop or commission info, just can't be the main purpose of the website.
  • No websites with hateful (racist, homophobic, transphobic, etc.) content.
  • You must link back to the webring with one of the codes within 1 month of being added as a member.
  • An 88x31px button is preferred, but if you don't have one I'll use a placeholder with your site name.

resources

If you're here from one of my local posts or just found out about it through a poster around town, hello!

Making your own website is a fun way to express yourself and share what you like without worrying about typical social media metrics. Your website can be about anything you want, whether that's a personal daily blog or a photo album or a niche hobby wiki.

Making a website can be free—all you need is access to a computer! (Or phone, depending on which method you use.) You don't need to code, either, though coding will give you the most freedom of customisation.

This resource section is designed for personal sites and blogs since that's what I'm more familiar with, but it might still be useful for other website types!

Note: Any prices listed are in USD. 1 USD is currently around 1.7 NZD.

Making a website for free

No-code options

If you aren't familiar with HTML/CSS and want to make a website without coding, you could use one of these free platforms. While they're all designed for blogs, you can use them as website builders too.

Platform Description
Bear Blog Uses a markdown editor. Lots of default themes and easy to customise with simple CSS. Bear Blog has a built in global discovery feed, so you can easily read others' blog posts or include/opt out from including your posts in the feed. Adding a custom domain requires a $5 monthly subscription.
Blogger Uses a visual editor. Hasn't really been actively worked on for the past decade, but it's easy to use.
Hatena Blog Uses a markdown and visual editor which I find the easiest. Lots of themes; includes ads by default but you can hide these pretty easily with CSS. The site pretty much only used in Japan but there's an English UI option.

Coding options

If you already know how to code or want to learn, these are some free ways you can put a static site online.

Platform Description
GitHub Pages Make a static website out of the files from a GitHub repo. Definitely my top recommendation—it's super easy to set up if you're already familiar with using GH. If you haven't used GH before, there's a little bit of a learning curve but I think that the benefits are worth it. Adding a custom domain is free.
Netlify Another developer-oriented option with a free tier that includes access to Netlify Database. Adding a custom domain is free.
Neocities A Geocities revival project, very popular with beginners. Notably, it has a social system where users can follow each other to see updates on their statuses and sites (which can be a pro or con). Adding a custom domain requires a $5 monthly subscription.
Nekoweb Alternative to Neocities with some more features. Adding a custom domain requires a $3.5 monthly subscription.

For more information, read 32bit.cafe's guide to creating your own website.

You can also set up your website through a paid server host—I recommend nearlyfreespeech.net as it lets you only pay what you use (my hosting fees are approx. 45c per month!).

Or you can use a paid VM service like the NZ-based rimuhosting. I don't know how this works but if you know what a VM is you already have more experience than me.

Reading other websites

But how can your friends follow your updates when you're not using Instagram? Use the web standard RSS (Really Simple Syndication)!

RSS is everywhere; if you've ever used Substack or Tumblr or visual website builders (Wix, Squarespace, etc.) you probably already have a RSS feed!

In fact, most websites that do any kind of regular updating have RSS feeds, except for social medias. That's because social media companies want to keep you on their apps, looking at algorithms and ads, instead of seeing the content you signed up for.

To follow RSS feeds, you can use a RSS reader. There are a lot of options out there; I use Reader You, which is a fully free option with the data only stored on your local device. If you want to have the same RSS data across multiple devices, I recommend Feedly, which is free for up to 100 feeds.

To add start following a RSS feed, all you have to do is copy the website's feed URL to your RSS reader. Here are some I follow:

  • https://www.rnz.co.nz/rss/community.xml
  • https://boilerroom.substack.com/feed.xml
  • https://joshreads.com/feed

You can easily export your list of RSS feeds and reimport them to a different reader if you ever want to change it. RSS also makes it easy to follow webcomics, podcasts, subreddits...

If you're using a blogging service like Blogger or WordPress, your RSS feed will update by default. If you're coding your website from scratch, you'll need to create your own RSS feed file (or just tell your friends to look at your website.)

This guide is a total WIP and I'll probably move it to my own site in the future. But hopefully that's enough to get you started; if you have any questions feel free to email me. I'm very happy to help you in your website journey!!
